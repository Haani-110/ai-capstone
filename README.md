# AI Capstone

This repository contains my AI-assisted development capstone assignment.

## Tech Stack

- Node.js (LTS)
- Git
- Cursor IDE
- GitHub

## Objective

Practice AI-assisted software development using modern development tools.

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (LTS)
- [Git](https://git-scm.com/)
- [Cursor](https://cursor.com/)

### Setup

```bash
git clone https://github.com/Haani-110/ai-capstone.git
cd ai-capstone
```

Open the project in Cursor and begin development.

### Run the settings app

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) to use the project settings form. Settings are validated on the client and server, then saved to `data/settings.json`.

For development with auto-reload:

```bash
npm run dev
```
